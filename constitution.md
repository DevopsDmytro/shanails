# Constitution for "Shanails" Project - v3.1

This document establishes the project's mandatory principles.

**1. Core Principles:**
    *   **Tech Stack:** Backend MUST use Python. Frontend MUST be a modern SPA.
    *   **Database:** Must be PostgreSQL.
    *   **Containerization:** The entire stack MUST be containerized via Docker Compose.
    *   **UX:** The experience must be fast, intuitive, and mobile-first.
    *   **Localization:** All user-facing text MUST be Ukrainian.
